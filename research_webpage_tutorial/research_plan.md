# Research Plan: 网页设计教程

## 核心问题
如何设计一个面向初学者的网页设计教程？教程应覆盖 HTML + CSS 核心知识，并以 HTML 文件形式呈现。

## 子主题

1. **网页设计教程的最佳结构** — 教程应如何分章节？从什么开始教？进阶路线是什么？
2. **HTML+CSS 核心知识点** — 初学者必须掌握的 HTML 标签和 CSS 属性有哪些？
3. **交互式教程的 UI 设计** — 如何让 HTML 教程本身美观、易读、有交互感？
4. **教程写作最佳实践** — 教学文案应该怎么写？代码示例应该如何呈现？

## 预期输出
一份完整的 HTML 教程文件，包含：
- 美观的教程 UI
- 系统化的知识结构
- 可交互的代码示例
