Chapter 01

环境搭建：创建你的第一个网页

不需要安装任何软件，一个文本编辑器 + 浏览器就够了

你需要什么？

编写网页只需要两样东西：文本编辑器（写代码）和 浏览器（看效果）。

推荐工具

编辑器：VS Code（免费，macOS/Windows/Linux）—— 最流行的代码编辑器。
浏览器：Chrome 或 Firefox —— 都自带强大的开发者工具（按 F12 打开）。

创建第一个 HTML 文件

在任意位置新建一个文件，命名为 index.html，用编辑器打开，输入以下内容：

index.html 
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>这是我的第一个网页。</p>
</body>
</html>

保存后，用浏览器打开这个文件（拖到浏览器窗口，或右键 → 打开方式 → Chrome），你就能看到你的第一个网页了！

预览效果

关键点

<!DOCTYPE html> 告诉浏览器"这是 HTML5 文档"。
<html> 是所有内容的根元素，lang="zh-CN" 表示页面语言是中文。
<head> 放元信息（标题、编码等），不显示在页面上。
<body> 里的内容才会在浏览器窗口中真正显示。

Chapter 02

HTML 文档结构

理解 HTML 元素、标签和属性的基本语法

元素 = 开始标签 + 内容 + 结束标签

HTML 的核心是元素（Element）。绝大多数元素由一对标签包裹内容构成：

元素语法
<标签名 属性="值">内容</标签名>

<!-- 例子 -->
<a href="https://example.com">点击这里</a>
<img src="photo.jpg" alt="一张照片">  <!-- 空元素：没有结束标签 -->

属性（Attribute）提供元素的额外信息，写在开始标签内，格式为 属性名="值"。

常见的 HTML 属性

class — 给元素起一个"类名"，用于 CSS 选择
id — 给元素一个唯一标识（一个页面中每个 id 只能出现一次）
href — 链接的目标地址
src — 图片/视频/脚本的来源路径
alt — 图片的替代文本（无障碍 + SEO 必备）

HTML 注释

注释不会在页面上显示，用于给代码做说明：

注释语法
<!-- 这是注释，浏览器会忽略它 -->

<!--
  多行注释
  可以跨越多行

Chapter 05

超链接与图片

让页面互相连接，展示视觉内容

超链接 <a>

href 属性指定目标地址。最重要的属性是 href 和 target。

链接示例
<!-- 跳转到外部网站 -->
<a href="https://developer.mozilla.org/zh-CN/">MDN 中文文档</a>

<!-- 在新标签页打开 -->
<a href="https://example.com" target="_blank">新标签页打开</a>

<!-- 跳转到页面内的某个位置（锚点） -->
<a href="#s3">跳转到第三章</a>

<!-- 发送邮件 -->
<a href="mailto:hello@example.com">发邮件</a>

图片 <img>

<img> 是空元素（没有结束标签）。alt 属性是必须的 —— 图片加载失败时显示替代文本，对屏幕阅读器也至关重要。

图片示例
<!-- 基本用法 -->
<img src="photo.jpg" alt="日落下海滩的风景照">

<!-- 指定宽高（防止布局抖动） -->
<img src="photo.jpg" alt="..." width="800" height="600">

<!-- 图片 + 标题（语义化） -->
<figure>
  <img src="chart.png" alt="2024 年销售数据柱状图">
  <figcaption>图 1: 2024 年度销售趋势</figcaption>
</figure>

常见错误

忘记 alt 属性 —— 即使图片是纯装饰性的，也应写 alt=""（空字符串），这样屏幕阅读器会跳过它。
图片路径错误 —— 相对路径是相对于 HTML 文件的位置。如果图片在 images/ 文件夹中，路径应为 images/photo.jpg。

Chapter 06

语义化元素

用正确的标签描述内容的意义，而不仅仅是外观

在 HTML5 之前，人们用 <div> 做一切布局。现在我们有语义化标签，让代码更有意义：

标签用途说明
<header>页眉页面或区块的头部（logo、导航、标题等）
<nav>导航主要的导航链接区域
<main>主要内容页面独有的核心内容，一个页面只能有一个
<section>章节主题相关的内容组，通常带一个标题
<article>文章独立、可分发的内容（博客文章、新闻等）
<aside>侧栏与主要内容间接相关的内容（侧边栏、广告等）
<footer>页脚页面或区块的底部（版权、联系方式等）
<div>通用容器无语义，纯布局用途。当没有更合适的语义标签时使用
<span>行内容器无语义的行内元素，用于包裹一小段文字以添加样式

典型页面结构

语义化布局
<body>
  <header>
    <nav>... 导航菜单 ...</nav>
  </header>

  <main>
    <article>
      <h1>文章标题</h1>
      <section>
        <h2>第一节</h2>
        <p>...</p>
      </section>
    </article>

    <aside>... 侧边栏 ...</aside>
  </main>

  <footer>... 页脚信息 ...</footer>
</body>

为什么要用语义化标签？

1. SEO：搜索引擎更好地理解页面结构
2. 无障碍：屏幕阅读器能准确描述页面区域
3. 可维护性：代码更易读，协作更高效

Chapter 08

表单

收集用户输入 —— 搜索框、登录、注册、调查问卷

表单示例
<form action="/submit" method="POST">
  <label for="name">姓名：</label>
  <input type="text" id="name" name="name" required>

  <label for="email">邮箱：</label>
  <input type="email" id="email" name="email" placeholder="you@example.com">

  <label for="msg">留言：</label>
  <textarea id="msg" name="msg" rows="4"></textarea>

  <label for="city">城市：</label>
  <select id="city" name="city">
    <option value="beijing">北京</option>
    <option value="shanghai">上海</option>
  </select>

  <button type="submit">提交</button>
</form>

<input> 的 type 属性决定了输入类型：

type 值用途
text单行文本（默认）
email邮箱地址（移动端弹出邮箱键盘）
password密码（输入内容被遮挡）
number数字（带增减按钮）
checkbox复选框（多选）
radio单选框（name 相同即为一组）
file文件上传
date日期选择器
submit提交按钮

重要原则

每个 <input> 都应该有一个对应的 <label>（通过 for 属性关联），这样点击标签文字就能聚焦输入框，大大提升可用性和无障碍体验。

CSS 语法与选择器

CSS 是网页的"化妆师"——控制颜色、字体、布局、动画

三种引入 CSS 的方式

方式代码推荐度
外部样式表<link rel="stylesheet" href="style.css">★★★ 最佳
内部 <style><style>h1 { color: red; }</style>★★ 小页面可用
内联样式<p style="color: red;">★ 尽量避免

CSS 规则结构

CSS 语法
选择器 {
  属性: 值;
  属性: 值;
}

/* 实际例子 */
h1 {
  color: #333333;
  font-size: 28px;
  text-align: center;
}

核心选择器一览

选择器语法匹配
元素（类型）p { }所有 <p> 元素
类（class）.highlight { }所有 class="highlight" 的元素
ID#header { }id="header" 的元素（唯一）
后代article p { }article 内部所有 p（任意层级）
子代ul > li { }ul 的直接子元素 li
分组h1, h2, h3 { }同时选择多个选择器
伪类a:hover { }鼠标悬停时的链接
通用* { }所有元素

最佳实践

优先使用 class 选择器，避免过度使用 ID 选择器（特异性太高，难以覆盖）。组合选择时：.card.highlight 选择同时拥有两个类的元素。

Chapter 11

CSS 文本与字体

控制文字的样式、大小、间距和对齐

文字排版大全
.article {
  /* 字体家族（优先使用第一个，找不到则回退） */
  font-family: 'Crimson Pro', Georgia, 'Times New Roman', serif;

  /* 字号 */
  font-size: 18px;

  /* 字重：400=正常, 700=粗体 */
  font-weight: 600;

  /* 行高：无单位的数字 = 字号倍数（推荐） */
  line-height: 1.75;

  /* 文字对齐：left / center / right / justify */
  text-align: left;

  /* 文字装饰：none / underline / line-through */
  text-decoration: none;

  /* 字母间距 */
  letter-spacing: -0.01em;

  /* 首行缩进 */
  text-indent: 2em;
}

Web 安全字体 vs 自定义字体

Web 安全字体是几乎所有系统都预装的字体（Arial, Georgia, Times New Roman 等）。自定义字体通过 Google Fonts 或 @font-face 引入。

Google Fonts 使用
<!-- 1. 在 <head> 中引入 -->
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display&display=swap"
      rel="stylesheet">

<!-- 2. 在 CSS 中使用 -->
<style>
  h1 { font-family: 'Playfair Display', serif; }
</style>
Chapter 12

CSS 盒模型 ★

理解 CSS 最核心的概念 —— 每个元素都是一个矩形盒子

在 CSS 中，一切皆为盒子。每个 HTML 元素都被渲染成一个矩形，由四层组成（从内到外）：

margin（外边距）—— 盒子之间的间距
border（边框）—— 可见的边界线
padding（内边距）—— 边框到内容的距离
content（内容）—— 文字/图片本身
层CSS 属性说明
contentwidth, height内容区域的大小
paddingpadding内容与边框之间的内部留白
borderborder围绕 padding 和 content 的边框
marginmargin盒子与其他元素之间的外部间距
盒模型实操
.card {
  width: 300px;           /* 内容宽度 */
  padding: 20px;          /* 内边距：上下左右各 20px */
  border: 2px solid #ccc; /* 边框 */
  margin: 16px auto;      /* 外边距：上下 16px，左右居中 */

  /* 简写技巧 */
  /* padding: 上 右 下 左; */
  /* padding: 20px 15px 10px 15px; */
  /* margin: 10px 20px; (上下 10px, 左右 20px) */
}

box-sizing 陷阱

默认情况下，width: 300px 只设置内容区的宽度。加上 padding 和 border 后，元素实际占用宽度 = 300 + 20×2 + 2×2 = 344px。

使用 box-sizing: border-box 可以让 width 包含 padding 和 border，这样设置 300px 就是 300px。几乎所有现代项目都会全局设置：

全局 border-box
*, *::before, *::after {
  box-sizing: border-box;
}
Chapter 13

CSS Display 与 Position

控制元素如何显示、如何定位

display 属性

值行为常见元素
block独占一行，可设宽高div, p, h1, section
inline不换行，不可设宽高span, a, strong, em
inline-block不换行，但可设宽高button（默认）
none完全隐藏，不占空间—
flex弹性布局容器—
grid网格布局容器—

position 属性

值行为
static默认值，按正常文档流排列
relative相对于元素原本的位置偏移（不脱离文档流）
absolute相对于最近的定位祖先（非 static）定位，脱离文档流
fixed相对于浏览器视口定位，滚动页面时不动（如固定导航栏）
sticky滚动到一定位置后"粘住"（如本页面的侧边栏头部）
定位示例
/* 固定导航栏 */
.navbar {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  background: white;
  z-index: 100;   /* 层级：数值越大越靠前 */
}

/* 绝对定位的弹出菜单 */
.dropdown {
  position: absolute;
  top: 100%;
  left: 0;
}
Chapter 14

CSS Flexbox ★

现代网页布局的基石 —— 一维弹性布局

Flexbox 让你轻松实现水平或垂直排列、居中对齐、等宽分布等布局。只需要在容器上设置 display: flex，其直接子元素自动变为"弹性项目"。

容器属性（设置在父元素上）

属性常用值作用
flex-directionrow / column主轴方向：水平（默认）或垂直
justify-contentcenter / space-between / space-around主轴上的对齐方式
align-itemscenter / flex-start / flex-end交叉轴上的对齐方式
flex-wrapwrap / nowrap是否允许换行
gap16px / 1rem项目之间的间距

三大经典布局

Flexbox 经典模式
/* 1. 水平居中 + 垂直居中（万能居中） */
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 2. 导航栏：logo 在左，菜单在右 */
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* 3. 等宽三列 */
.row {
  display: flex;
  gap: 20px;
}
.row > * {
  flex: 1;  /* 每个子元素平均分配空间 */
}

Chapter 15

CSS CSS Grid

二维网格布局 —— 同时控制行和列

Flexbox 适合一维布局（排成一行或一列），Grid 适合二维布局（行和列同时控制）。

核心属性

Grid 基础
.container {
  display: grid;
  /* 定义三列：两侧固定宽度，中间自适应 */
  grid-template-columns: 200px 1fr 200px;
  /* 定义行高 */
  grid-template-rows: auto;
  /* 间距 */
  gap: 16px;
}

三种经典 Grid 布局

Grid 经典模式
/* 1. 响应式卡片网格（自动适配列数） */
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 24px;
}

/* 2. 经典页面布局（header / sidebar / main / footer） */
.page-layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  grid-template-columns: 250px 1fr;
  gap: 0;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

/* 3. 三列等宽 */
.three-cols {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Chapter 16

响应式设计

让网站在手机、平板、电脑上都好看

四大核心技巧

技巧代码说明
视口 meta 标签 <meta name="viewport" content="width=device-width, initial-scale=1.0"> 必须放在 <head> 中，告诉手机浏览器按设备宽度渲染
媒体查询 @media (max-width: 768px) { ... } 根据屏幕宽度应用不同样式
弹性图片 img { max-width: 100%; height: auto; } 图片不会超出容器宽度
相对单位 rem, %, vw, vh 避免使用固定 px，让尺寸随屏幕变化

移动优先的媒体查询

推荐的做法：先写移动端的样式（基础），然后用 min-width 从小到大地添加桌面端增强：

移动优先
/* 基础样式：面向手机（窄屏） */
.card {
  padding: 16px;
  margin-bottom: 12px;
}

/* 平板及以上（≥ 768px） */
@media (min-width: 768px) {
  .card {
    padding: 24px;
    margin-bottom: 20px;
  }

  .card-grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 20px;
  }
}

/* 桌面端（≥ 1024px） */
@media (min-width: 1024px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

常用断点

断点目标设备
max-width: 576px小屏手机
max-width: 768px平板 / 大屏手机
max-width: 992px小平板横屏 / 小笔记本
max-width: 1200px普通桌面显示器

响应式设计口诀

移动优先，从小到大写；能不用 px 就不用 px；图片要弹性；Grid 的 auto-fit 是神器。

Chapter 17

层叠与优先级

当多个 CSS 规则作用于同一个元素时，谁说了算？

CSS 全称是层叠样式表（Cascading Style Sheets），"层叠"就是它解决冲突的机制。

优先级规则（从低到高）

  1. 元素选择器（如 p, div）— 权重最低
  2. 类选择器（如 .card）、属性选择器、伪类 — 中等权重
  3. ID 选择器（如 #header）— 高权重
  4. 内联样式（style="..."）— 仅次于 !important
  5. !important — 最高权重（尽量不用！）

当优先级相同时，后写的规则覆盖先写的。

优先级演示
/* 元素选择器 — 权重低 */
p { color: black; }

/* 类选择器 — 覆盖上面的 */
.intro { color: blue; }

/* 更具体的选择器 — 再覆盖 */
article p.intro { color: green; }

/* ID — 最高（但尽量不用） */
#special { color: red; }

实用建议

用 class 做样式，不要用 ID。 ID 优先级太高，后面很难覆盖。
尽量不要用 !important —— 如果用了 !important 才能生效，说明选择器设计有问题。
保持选择器简单 —— 最多两层嵌套（如 .card .title），太深的选择器既难维护又影响性能。
